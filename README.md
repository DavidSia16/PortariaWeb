# PortariaWeb

Sistema de controle de portaria desenvolvido para gerenciar o acesso de visitantes, prestadores de serviços, registro de entradas/saídas e controle de entregas de encomendas para condomínios.

## Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

- **Java 17+**
- **Spring Boot** (Spring Data JPA, Spring Security, Web)
- **PostgreSQL** (Banco de dados relacional)
- **Hibernate / JPA** (Mapeamento objeto-relacional)
- **Docker** (Containerização da aplicação)
- **Render** (Plataforma de hospedagem e deploy contínuo)

---

##  Funcionalidades

- **Controle de Acessos:** Registro e monitoramento de entrada e saída de moradores, visitantes e prestadores de serviços.
- **Gestão de Encomendas:** Cadastro de recebimento e retirada de pacotes e correspondências.
- **Segurança:** Autenticação e controle de rotas utilizando Spring Security.
